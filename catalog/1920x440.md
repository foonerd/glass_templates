## 1920x440_Aluminium_spectrum

**Type:** Combined

![1920x440_Aluminium_spectrum](../templates_peppy_spectrum/1920/440/previews/1920x440_Aluminium_spectrum.png)

**Meter:** Aluminium_spectrum

**Download:** [1920x440_Aluminium_spectrum.zip](../templates_peppy_spectrum/1920/440/1920x440_Aluminium_spectrum.zip)

**Install (both required):**
1. Extract the zip file
2. Copy `templates/1920x440_Aluminium_spectrum/` to `/data/INTERNAL/glass/templates/`
3. Copy `templates_spectrum/1920x440_Aluminium_spectrum/` to `/data/INTERNAL/glass/templates_spectrum/`

Or press Install on the Catalog tab of the Glass Manager.
